## 🛡 Introducción
Este documento explora el panorama actual de las amenazas cibernéticas que enfrentan las organizaciones. Analizamos la composición de un entorno de amenazas, desde el software malicioso hasta la ingeniería social, y cómo estas vulnerabilidades pueden comprometer la integridad operativa y financiera de una empresa.

---

## ⚠️ Amenazas Cibernéticas: Definición e Impacto
Las organizaciones dependen de la integridad de sus sistemas. Los cibercriminales aprovechan debilidades en el hardware y software, o utilizan la manipulación psicológica (ingeniería social), para:
* **Interrumpir operaciones**: Paralizando la productividad.
* **Secuestrar información**: Mediante ransomware para extorsión.
* **Minar criptomonedas (Cryptojacking)**: Consumiendo recursos de cómputo de forma ilícita.

---

## 🎯 Clasificación de Amenazas (Vectores de Ataque)

### 1. Malware
* **Virus vs. Gusanos**: Los virus requieren la ejecución del usuario; los gusanos se autorreplican a través de la red.
* **Troyanos**: Se ocultan como software legítimo para abrir puertas traseras.
* **Ransomware**: Cifra bases de datos y exige pagos en criptomonedas.

### 2. Ingeniería Social
* **Pretexting**: Creación de historias falsas (ej. hacerse pasar por soporte técnico) para manipular a los usuarios y obtener información confidencial.

## 🏗 Estrategias de Mitigación

Para fortalecer la postura de seguridad, se proponen las siguientes líneas de acción:

| Estrategia | Descripción |
| :--- | :--- |
| **Autenticación Robusta** | Uso de contraseñas fuertes (complejidad, longitud) para mitigar fuerza bruta y *spraying*. |
| **Cifrado de Comunicaciones** | Implementación de estándares como WPA2/WPA3 para evitar el robo de datos en redes Wi-Fi. |
| **Seguridad Física Perimetral** | Bloqueo de infraestructura física (routers, switches) para evitar accesos internos no autorizados. |
| **Concientización y Mantenimiento** | Parcheo constante de sistemas y capacitación al personal sobre riesgos de USBs y correos sospechosos. |
